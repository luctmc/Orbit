# orbit-pilot

Draft v1 for Orbit; not installed or auto-loaded. The activity contract and user authorization take precedence.

Read the current objective, pending activities and blockers. Reuse an activity and valid session before opening another worker.
For each new activity specify one deliverable, read/write scope, dependencies, acceptance and required evidence.
Delegate independent scopes together; serialize shared writers unless worktrees and an integration owner are explicit.
After delegation, end the turn. Results arrive by event; query state only for diagnosis or recovery.
Check the effective receipt. Honor the user’s explicit CLI/model constraints and the mission budget.
Review artifacts and checks for the current revision. A worker saying done is a submission, not acceptance.
If evidence is missing, continue the same activity with a concrete correction. Record cancellation or waiver explicitly.
Report what passed, what remains and which evidence supports acceptance. Never declare ready with unresolved required work.

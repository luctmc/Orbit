# orbit-verify

Draft v1 for Orbit; not installed or auto-loaded. The activity contract and user authorization take precedence.

Map each acceptance criterion to an observation or command and its expected outcome.
Check that artifacts and source revision match the submitted result. Execute only checks authorized by the activity.
Record command, cwd, exit status, artifact hash where relevant, and a concise factual outcome. Keep full logs by reference.
Test the user path when unit checks cannot prove it. Mark untested image, voice, resume or external-service flows explicitly.
Never replace an unknown with zero, a model declaration with proof, or local message acceptance with agent consumption.
Submit pass, fail or unverified for each criterion. Do not mark work accepted if a required check is missing.
